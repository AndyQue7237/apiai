# 01 Explore (Context & Brainstorming)

**Handover — Input**: User's initial request or idea.

1. **Act as a Consultant**: Discuss the user's goals and context.
2. **Analyze**: Explore the current codebase and architecture to see how new ideas fit.
3. **Brainstorm**: Propose solutions and discuss pros/cons.
4. **Evaluation Discussion**: Ask "How do we evaluate this?" - discuss test methods and success criteria.
5. **Constraint**: No implementation code. Focus on shared understanding.
6. **Feature Brief**: Summarize user context, goals, chosen approach, and evaluation plan.

**Handover — Final Output of Explore**: A **Feature Brief** summarizing context, goals, approach, and how we will evaluate success.

**Persistence**: Ask the user if the brief should be added to CLAUDE.md under "Active Context".

**⚠️ MANDATORY NEXT STEP**: Always proceed to **Plan phase**. Ask the user: "Explore complete. Ready for Plan phase?"

**Workflow:**
```
Explore → Plan → Build → Evaluate → Review → Revise → Verify
   ↑
YOU ARE HERE
   ↓
NEXT: Plan
```
