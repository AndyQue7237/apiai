# 03 Build (Implementation)

**Handover — Input**: Review the **Technical Blueprint**, **Evaluation Strategy**, and **Definition of Done** (DoD) before coding (check CLAUDE.md "Active Context" if stored there).

1. **Implementation**: Write clean, production-ready code.
2. **Standards**: Follow established conventions, use environmental variables for secrets, and ensure robust error handling.
3. **Context**: Maintain consistency with existing tools and structures.
4. **Quick Sanity Check**: Run a quick local test to verify the code works:
   - Does it run without errors?
   - Does basic functionality work?
   - This is NOT the full evaluation (that comes next).

**Handover — Final Output of Build**: Summary of implemented changes and any deviations from the plan.
